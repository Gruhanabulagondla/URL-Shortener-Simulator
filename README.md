# URL Shortener Simulator 🌐

A Python-based URL Shortener Simulator that converts long URLs into short codes and retrieves the original URLs.

## Features

- Shorten long URLs
- Generate unique short codes
- Retrieve original URLs
- View stored URLs
- Menu-driven interface

## Technologies Used

- Python
- Dictionaries
- Random
- Strings
- Functions

## How to Run

python url_shortener.py

## Concepts Used

- Dictionaries
- Functions
- Loops
- Random code generation
- String handling
- Key-value mapping

## Purpose

This project helps in understanding dictionaries, random code generation,
functions, and URL mapping logic.
